# China Trip Companion 2026

Guía de viaje móvil y offline para Pekín, Xi'an y Shanghái del 30 de octubre al 8 de noviembre de 2026.

## Qué incluye

- Pantalla “Hoy” adaptada automáticamente a la fecha del viaje.
- Itinerario completo con nombres en chino y acceso a Amap.
- Hoteles, transporte, pagos, emergencias y frases útiles.
- Checklist y notas guardadas localmente en el dispositivo.
- PWA instalable y disponible sin conexión después de la primera carga.

## Publicación

El workflow de GitHub Actions publica la carpeta `dist` mediante GitHub Pages con cada cambio en `main`.

Si Pages aún no está activo, entra en **Settings → Pages → Build and deployment** y selecciona **GitHub Actions**.
